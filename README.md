# Mockey Redux

Mockey Redux is a Kotlin rewrite of [Mockey](https://github.com/clafonta/Mockey),
with the mock engine, admin API, server, and UI split into independently testable
modules. It is currently under active development and is not yet a drop-in
replacement for Mockey 2.x.

The project is licensed under GPL-2.0-or-later. See [LICENSE](LICENSE) and
[docs/deviations.md](docs/deviations.md) for the intentional differences from
the legacy implementation.
