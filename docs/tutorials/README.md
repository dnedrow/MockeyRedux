# Tutorials

These tutorials walk through building a mock service from start to finish. Each one mocks the same live API,
the NHTSA vPIC `GetModelsForMakeId` endpoint, so the results are easy to compare.

| Tutorial | What it covers |
|---|---|
| [Create a service from the command line](create-service-cli.md) | Drive the admin API with `curl` to create a service, record real traffic, save scenarios, and switch to static mode. |
| [Create a service in the UI](create-service-ui.md) | Do the same work in the browser, with screenshots of each step. |

Both tutorials end with the same mock, so pick whichever fits the way you work. The command-line version suits
scripts and automation, and the UI version is the quicker way to explore.
